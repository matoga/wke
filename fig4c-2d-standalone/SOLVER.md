# Solver notes

The numbered sections refer to `wke_chain_2d.ts`.

1. **Scales.** The source density n₃ (µm⁻³) and a (µm) set ℓ_z = n₃^(-1/3), n₂ = n₃ℓ_z, and g̃ = √(8π)a/ℓ_z. Thus ξ = (2g̃n₂)^(-1/2), t₀ = 1/[(ħ/m)g̃n₂], and `NCAL = 4πn₂ξ²`. `--lz` replaces ℓ_z.
2. **Grids.** The state grid is logarithmic in p=kξ. Partner momenta use logarithmic Gauss–Legendre panels. The cutoff p_max/√2 keeps energy-conserving p₃ on the state grid.
3. **Initial state.** q(k) = 2πk n_k is normalized to one, interpolated to the state grid, then converted to f(k)=2πn₂q(k)/k. The discrete density integral is renormalized to n₂. Both peak estimators use kf.
4. **Collision geometry.** p₃²=p₁²+p₂²−p². For p,p₁,p₂,p₃, set a=|p−p₁|, b=p+p₁, c=|p₂−p₃|, d=p₂+p₃. The 2D angular factor is I=∫ QdQ/√[(Q²−a²)(b²−Q²)(Q²−c²)(d²−Q²)] over the intersection of both transfer intervals. The full angular delta integral is 16I. Resonance reduces I exactly to K(k)/(2P), where P=max(pp₃,p₁p₂), k=min(pp₃,p₁p₂)/P, and 1−k²=|(p²−p₁²)(p²−p₂²)|/P². The code evaluates K by the arithmetic-geometric mean. At exactly coincident endpoints the quartet is trivial and its collision bracket vanishes; it is omitted without a cutoff. The event weight is w₁w₂p₁p₂I. The p₂ panels split at p and p₁ to isolate geometry changes. The collision prefactor is 32/(π NCAL²).
5. **Transfer average.** For the dressed vertex only, each event's angular measure is sampled in x=Q² using the cosine endpoint substitution. Positive weights are projected once onto the pair's transfer table, then compressed into a sparse row. Each ordinary event is a sparse dot product with the vertex table. `--q-nodes` controls the projection order (draft default 4; standard/high 12). The exact elliptic event weight is independent of this order.
6. **Bubble.** For x=|A|/(2Q), the radial functions are R(x)=∫₀ˣ sf(s)/√(x²−s²) ds and I(x)=∫ₓ∞ sf(s)/√(s²−x²) ds. The code integrates these exactly for each linear f cell and tabulates the resulting matrices on a logarithmic x grid. R and I are multiplied by the current f at every RHS call. Real and imaginary L₋ are differences at A=ω+Q² and A=ω−Q², with the retarded branch sign. Low- and high-x limits extend the table.
7. **Chain.** The vertex is 1/|1−L₋|². The pair table has endpoints and midpoints of each Q cell. Fixed pair Q and ω values have cached bubble-table indices and interpolation fractions. A prefix count marks cells where the sampled denominator is below 0.04 or the real part crosses zero with small imaginary part. Events intersecting those cells split their angular interval at cell boundaries and use local 8/16/32/64-point refinement; other intervals retain the sparse average. This changes only numerical quadrature and introduces no physical broadening. `--chain off` sets the vertex to one for diagnostics.
8. **RHS.** The gain and loss factors retain the source's classical or Bose +1 choice, with the 2D event weights and prefactor. All momenta are dimensionless in p=kξ and time in τ=t/t₀.
9. **Observables.** n₂ is proportional to ∫kfdk, and kinetic energy to ∫k³fdk. A low-k fit ln f=A+Bk² gives ℓ̄²=f₀/n₂. Its directional derivative along the RHS gives (m/ħ)dℓ̄²/dt, without the 3D 2/3 factor.
10. **Integration and output.** Dormand–Prince 5(4), dense time sampling, wall cap, and JSON checkpoints follow the source solver. The wall deadline is checked within each RHS, so a slow near-pole evaluation still saves the last accepted state. `--tau-stop` selects a common dimensionless end time for convergence comparisons. The figure script pools the mapped 2D series and shows the published 3D points only as a grey reference.

Conservation drift is a numerical diagnostic, not proof of physical validity. The mapping and finite grid are model assumptions. Near a sharp dressed-vertex pole, resolving the dynamics can still take much longer than an initial-state RHS benchmark suggests.
